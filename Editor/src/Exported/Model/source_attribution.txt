PLACEHOLDER TEST ASSET — NOT PART OF THE ENGINE, DO NOT SHIP AS-IS.

This model exists only to exercise the importer, the material system and the
renderer with real multi-texture geometry. It is scheduled for replacement by
first-party materials that need no attribution.

No licence has been recorded for it. Attribution alone does not establish a
redistribution right, so it does NOT ship: Player/unshipped_assets.txt lists
these files and both install routes in Player/CMakeLists.txt leave them out of
every bundle (ADR-019 D10, 2026-09-06). It stays here for the editor's demo
scene. To ship it one day, check the Sketchfab page below, record the licence
in CREDITS.md beside it (see Env/CREDITS.md and Fonts/README.md for the
pattern) and take it off the unshipped list.
