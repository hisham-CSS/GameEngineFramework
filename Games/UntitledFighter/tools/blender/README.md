# Blender tools of record

Every script here runs **headless** — `blender --background [file.blend] --python <script>` —
and every byte it commits is regenerable from it. That is the path of record
([ADR-019](../../../../docs/adr/ADR-019-placeholders-through-blender.md) D8);
the `blender-mcp` server is an interactive aid for iteration and screenshots,
never a step a committed asset depends on. How to set either up, and the rules
that go with them, is [the art-pipeline manual page](../../../../docs/manual/art-pipeline.md).

| Script | Does |
|---|---|
| `common.py` | The one export function. Pins every glTF exporter option that could make a clip disagree with its frame data (sampling on, frame step 1, Optimize Animation Size **off**, no playback-range limit, slide to zero, deform bones only, rest-position armature, 4 influences, no morphs, no Draco, +Y up, one animation per action), writes the `<stem>.clips.json` sidecar, and refuses to run against an exporter that lacks a pinned option (`selftest()`) or a deform skeleton that drifted from `rig_manifest.json`. |
| `export_gltf.py` | Exports the open `.blend` through `common.py`: `blender --background file.blend --python export_gltf.py -- --out X.gltf [--armature Rig] [--manifest rig_manifest.json]`; `-- --selftest` checks the exporter only. |
| `make_paddle.py` | The committed Blender-exported witness beside the stdlib fixtures: a two-bone paddle with **two** stashed actions (`paddle_swing` 14 stepped keys, `paddle_hold` 5), written to `tests/fixtures/models/paddle_blender.gltf` with its `.bin` and sidecar. `scripts/check_clips.py --self-test` reads it in CI. |
| `make_mannequin.py` | The placeholder fighter's rig and body (ROADMAP M3.3b), as a module: `build_mannequin(height)` makes Rigify's **basic** human metarig scaled to 60 units with feet at z = 0 and facing +X, generates it, deletes the control layer and re-parents the 33 deform bones along the metarig's hierarchy (one tree rooted at the hips), builds a body of primitives along the bones bound by automatic weights capped at 4 influences; `write_model_files` writes `rig_manifest.json` (first run only, **enforced** after), `rig_bones.json` (the semantic names the pose library is written against), the export and `CREDITS.md`. Run alone it exports the rig with a 2-frame `idle` for inspection and refuses to run without `--out`, so it cannot overwrite the committed clips. Rigify is enabled through the preferences operator — `addon_utils.enable(default_set=False)` leaves its parameters unregistered and generation fails with a misleading `make_custom_pivot` error. `tests/test_placeholder_rig.cpp` holds the committed rig. Regeneration is byte-identical (weights snapped to 1/255, faces sorted by centroid — bone heat and the UV-sphere primitive were both measured to drift run to run otherwise), so `git diff` on the model directory means a change. |
| `make_move_clips.py` | **The script of record for the committed model** (ROADMAP M3.3c): builds the mannequin, reads `fighter_a.json` and `poses.json`, keys ONE STEPPED POSE PER FRAME for every attack (anticipation over `startup`, the contact pose HELD over `active`, recovery converging on idle) and every reserved cycle (lengths from the file's largest counters: `knockdown` exactly the largest `knockdownTicks`), and exports through `common.py` to `Games/UntitledFighter/Assets/Characters/fighter_a/model/`. Attack poses come from `poses.json` `moves` (`_default`, overridden by `by_tag` — single tags, then `crouch+kick`-style combinations — overridden by the move id). A cycle with a `walk` entry gets its legs from a generated gait at the kernel's walk speed (each foot planted for half the cycle sliding back exactly one frame's travel, two-bone IK, the same clip serving forward and back because a backward walk plays it in reverse); its keys pose the rest of the body. `--blend <path>` saves the scene for a viewport session. Held by `tests/test_shipped_clips.cpp` (frame counts, counters, the contact pose inside the body the kernel can hit, the stride) and the CI `check_clips.py` step. |
| `poselib.py` | `poses.json` on disk (bpy-free): `load`, and `dump` in the one layout the file is kept in, so a capture changes the pose it captured and nothing else. |
| `capture_pose.py` | Writes the pose at the viewport back into `poses.json` as `{"q": [w, x, y, z]}` per bone plus `hips_drop`: `blender --background scene.blend --python capture_pose.py -- --pose <name> [--clip <clip> --frame <n>]`. The NLA's solo flag cannot be set from a script, so `--clip` assigns the clip's action first; at the viewport, assign the action or solo the track, pose, save, run. |
| `make_training_room.py` | The training room (ROADMAP M3.5a): reads `stage_dims.json` (half width, pinned by `StageAsset.TheFloorSpansExactlyTheKernelsStage` to the kernel's `kStageHalfWidthSub`; cells; the heavy-line spacing, one reach unit; wall height) and `fight_look.json` (`room_depth_px`, `fighter_depth_px`), builds the floor, three walls, the light and heavy grid, the red centre line and the blue plane marks from coordinates (no primitive operator, so a regeneration is byte-identical), one mesh per material named `floor`, `wall`, `grid_light`, `grid_heavy`, `centre_line`, `plane_mark`, and exports to `Games/UntitledFighter/Assets/UntitledFighter/Stage/` with a `CREDITS.md`; no sidecar (a static asset). |
| `draw_boxes.py` | Draws a move's kernel boxes as wire cubes in the open scene at its contact frame (`-- --move stand_lp`): the body hurtbox and the reach-derived hitbox exactly where `MatchBuilder` puts them, so a screenshot shows fit, not opinion. |

**Frame zero.** Actions are keyed from Blender frame 0 with an explicit frame
range, so sample `k` is Blender frame `k` and the first sampled time is 0 —
`moveFrame 0`, the tick a move starts. New keys are CONSTANT (set through the
keyframe preference before insertion: Blender 5 stores F-curves under an
action's slots, not `Action.fcurves`).

**Self-test record.** `export_gltf.py -- --selftest` and `make_paddle.py`
passed on Blender 5.2.1 LTS (build 2026-08-25) on 2026-09-02; the exporter
exposed every pinned option. CI never runs Blender — its witness is the
committed paddle.
